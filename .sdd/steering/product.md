# Product

この文書は、製品の目的と判断基準を永続的に記録する。機能一覧ではなく、今後の仕様判断に
使える価値と境界を示す。

## Purpose

Next Agentic Stack は、Next.js App Router と Vercel AI SDK で AI エージェントアプリを
始めるための軽量スターターである。同時に、統合ハブ `vaz-agentic-ai-next` が安定版へ
移行する前に、TypeScript、Node.js、Next.js、テストツールなどの次期版を検証する
ベータレーンとして機能する。

この二つの役割を両立し、利用者には理解しやすい出発点を、ハブの保守者には採用判断に使える
再現可能な証拠を提供する。

## Users & Value

| User / persona | Need | Value delivered |
|----------------|------|-----------------|
| AI アプリ開発者 | 最小構成から安全に開発を始めたい | チャット、ツール実行、入力防御、テスト、CI を備えた出発点 |
| ハブ保守者 | 次期ツールチェーンの採用可否を判断したい | 対象版、再現手順、品質ゲート、未解決事項を含む検証記録 |
| コントリビューター | 変更すべき場所と品質基準を素早く理解したい | 一貫した構造、型安全な境界、外部サービス不要の検証方法 |

## Core Capabilities

- **複数 AI プロバイダ対応のストリーミングチャット** — Anthropic、OpenAI、Ollama を
  共通の UI とエージェント境界から切り替えられる。
- **制約付きツール実行** — 明示的な入力スキーマと反復回数上限を持つエージェントパターンを
  実例として示す。
- **モデル呼び出し前の API 防御** — レート、本文サイズ、strict schema の順で不正・過大な
  リクエストを拒否する。
- **外部依存を隔離した検証基盤** — 単体テストと E2E で実 LLM を呼ばず、API キーなしで
  主要な動作を再現する。
- **ベータ版の採用証拠** — プレリリース版で通過したゲートと残課題を記録し、ハブへ手順と
  判断材料を渡す。

## Product Principles

- **軽量性を守る**: 新機能はスターターの基礎能力またはベータ検証に直接必要な場合だけ追加する。
- **証拠を成果物にする**: 「動いた」ではなく、対象コミット、版、手順、結果、未解決事項を残す。
- **ハブを正本にする**: ハブ由来の機能や UI は互換性を検証し、独自製品として分岐させない。
- **安全な既定値を示す**: 型安全、入力上限、サーバー境界、供給網防御をサンプルでも省略しない。
- **CI を自己完結させる**: 実 LLM や秘密情報に依存せず、変更の妥当性を自動判定できるようにする。

## Out of Scope

- 認証、RBAC、耐久ワークフロー、承認フロー、RAG、Python API などの本番プラットフォーム機能
- ハブの設定や機能を丸ごと複製し、このリポジトリを第二の統合製品にすること
- 実 LLM を使う品質評価、プロンプト評価、課金を伴う CI
- ベータレーンで得た結果だけを根拠に、ハブの安定版方針をこのリポジトリ側で決定すること
