LTS で全 gate を通る」ことの証拠であり、ハブ自身の互換性の証拠ではない。ハブ側の検証は spec `011` の事前検証が

## 結論

公式 metadata が Node 26 を Active LTS(`Lithium`)と示した後の版、26.13.1 で、本リポジトリの gate
(`biome`・`typecheck`・Vitest・`next build`・`size`・`audit`)と Playwright E2E(Chromium)がすべて通った。
Node 26 に起因する変更は不要だった。したがって、§8.1 の「`@types/node` `^24` は Node の判断が先」という
据え置きのうち、「Node 26 の LTS 化と、Next.js・Vitest・Playwright・TypeScript 7 nightly が Node 26 で動くか」
という部分は解消とする。

一方、ハブ固有の障害は本リポジトリでは測れない。ハブには Node の型除去で動く worker ローダー
(`apps/worker/typescript-loader.mjs`)があり、spec `011` の事前検証によれば Node 26 で
`stripTypeScriptTypes` の `mode: "transform"` が `ERR_INVALID_ARG_VALUE` になり、`module.register()` は
DEP0205 で非推奨になった。本リポジトリはどちらも使わないため、この系統の証拠は持たない。判定を部分解消とした理由である。
