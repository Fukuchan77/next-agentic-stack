## ハブへ持ち込むときの注意

設定 file は渡さず、この記録と再現手順だけをハブの `docs/dependency-policy.md` §8 の手順で渡す。
部品の正本はハブで、本リポジトリは部品を独自に拡張しない。

ハブへ報告する観察:

1. `ToolExecution` は `state="output-denied"` で `errorText` を渡さないと「完了」badge を表示する。却下理由を
   `errorText` で渡せば alert になり badge は消える(fixture で確認)。adapter が常に理由を渡す契約なのか、
   部品側で `output-denied` を別扱いにすべきかはハブで判断してほしい。
2. ハブの `card.tsx`・`button.tsx` は `forwardRef` 世代、本リポジトリは function component + `data-slot`
   世代である。agent-ui は `Button` の `variant`(`default`・`outline`)と `disabled`、`Card` 系 5 export しか
   使わないので両世代で動くが、コピー先の `card.tsx` に `CardHeader`・`CardTitle`・`CardFooter` が必要になる。
   `from-genai-to-agentic-ai` など他のコピー先でも同じ確認が要る。
3. ハブ spec 009 R2.3 は props を `@vaz/schemas` と AI SDK v7 の型から導くと書くが、実 source の props は文字列・
   真偽値・callback だけの中立型で、`@vaz/schemas` を import しない。コピーにはこの方が都合がよい。spec と実装の
   表現の差として記しておく。
